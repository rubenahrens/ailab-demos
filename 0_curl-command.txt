curl https://api.openai.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "gpt-6-luna",
    "messages": [{"role": "user",
      "content": "Write a bedtime story about the Netherlands winning the 2026 world cup."}]
  }'


Met dit curl-commando stuur je vanuit de terminal een verzoek (request) naar de API van OpenAI.
Je vraagt de AI om een slaapverhaaltje over hoe Nederland het WK voetbal van 2026 wint.

Wat elk onderdeel doet:
• curl: een command-line programma waarmee je gegevens naar een server stuurt en het antwoord terugkrijgt.
• https://api.openai.com/v1/chat/completions: het adres (endpoint) van de Chat Completions API van OpenAI.
  Dit is dezelfde API die je Streamlit-app straks gebruikt.
• -H "Content-Type: application/json": een header die zegt dat de meegestuurde gegevens JSON zijn.
• -H "Authorization: Bearer $OPENAI_API_KEY": je sleutel. $OPENAI_API_KEY is een variabele in je terminal
  waarin je key staat. Zonder sleutel weigert de server je verzoek.
• -d '{ ... }': de data (payload) die je meestuurt:
  • "model": "gpt-6-luna": welk model je gebruikt.
  • "messages": het gesprek tot nu toe. Hier één bericht van de gebruiker ("role": "user") met je prompt als "content".
